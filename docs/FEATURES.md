# 功能清单与边界

本文按**用户操作**而非历史开发阶段整理当前源码实现。某些功能依赖网络、外部软件或可选模型；“已实现”不等于“在任意环境下可离线运行”。

## 1. 字幕进入素材库

| 能力 | 说明 |
| --- | --- |
| 本地导入 | 选择或拖入 `.srt`、`.vtt`、`.txt`；支持多文件和常见中文编码，导入时解析时间轴。`.txt` 必须包含可识别的字幕时间格式。 |
| B 站拉取 | 识别视频 BV、合集/系列、收藏夹和 UP 主投稿页等链接；通过 B 站接口获取视频、分 P 和可用字幕轨。部分接口可能需要登录 Cookie。 |
| 浏览器用户脚本 | `userscript/SubClip.user.js` 在 B 站页面上向桌面端推送页面/字幕信息，亦支持拉取请求交互。需安装 Tampermonkey 等用户脚本管理器。 |
| 入库与去重 | 层级为 UP 主 → 合集 → 视频 → 字幕文档；同视频、分 P、语言的字幕重复导入会更新原文档。 |
| 旧数据迁移 | 启动时识别原有数据目录和旧版 JSON/SQLite 格式，按原迁移逻辑保留数据。升级前先备份。 |

## 2. 素材库与字幕阅读

- 资源树：按 UP 主/合集/视频/文档分组，支持收藏、重命名、标签、删除和撤销删除。
- 预览：使用 B 站可用 DASH 流；可折叠预览、切换分 P，并与字幕光标联动。需要网络及可访问的 B 站 CDN。
- 字幕正文：按时间轴阅读、选中、批量选择、复制、编辑、合并、拆分、时间平移和批量替换；支持撤销/重做、阅读样式与键盘操作。
- 选段：可按行或在时间轴上拖选；相邻字幕按可调间隔合并，跨分 P 范围可记录为多个子段。
- 导出：字幕文本及时间轴格式、CSV/XLSX 切片表等，具体入口在阅读工具、右栏和任务页。

## 3. 检索与内容理解

| 模式 | 说明 | 前置条件 |
| --- | --- | --- |
| 全库关键词 | SQLite FTS5 搜索跨文档正文，结合标题/文档名加权；支持范围、UP 主、标签、收藏、时间/时长筛选与分页。 | 已入库字幕 |
| 语义检索 | 下载本地向量模型，按字幕段落建索引后按意思检索；支持索引进度与清理。 | 模型下载、索引完成；首次需网络 |
| AI 辅助 | 摘要、标签建议、字幕解释、标题/文案相关操作；建议需用户确认后应用。 | 在设置中启用 Ollama 或 OpenAI 兼容 API |

默认 AI 后端为**关闭**。本地语义模型和 AI 语言模型是两套不同能力，不应混为一谈。

## 4. 从片段到成片

1. 在字幕中选择时间范围并保存为片段。片段是可复用素材，不等同于一次导出任务。
2. 在「片段库」对片段命名、收藏、加标签、按来源/标签筛选、返回原字幕位置。
3. 「发现」提供库内相似素材推荐；「探索」提供主题/视频/观点关系；「文案模板」提供可复用发布文案；「素材包」可组织文本素材和合成成片。
4. 将片段加入「剪辑任务」，选择输出设置并执行。任务状态、进度、失败重试、取消与历史记录独立于片段库。
5. 视频切片通过 B 站播放地址和 FFmpeg 处理，可能受登录、地区、网络、视频编码及版权限制影响。

## 5. 设置、备份与联动

- 浅色/深色/跟随系统主题、字体、字号、行距、预览跟随和可自定义快捷键。
- FFmpeg 路径、输出目录、画质、并发、命名模板；可检测环境。
- 本地数据库备份/恢复、清空数据、诊断信息导出；诊断输出会脱敏凭证字段。
- 浏览器用户脚本通信状态、端口、可选配对令牌；设置中可查看/复制脚本。
- Ctrl+K 快捷操作面板；拖动或键盘调整三栏宽度和预览高度，双击分隔线重置。

## 6. 不包含或不保证的能力

- **不是**云端视频托管/自动发布平台；素材包用于本地整理与导出。
- **不内置**可商用授权的 FFmpeg 可执行文件；需用户安装并遵守其许可。
- **不保证**所有 B 站视频都能拉到字幕或播放地址，受接口与账号权限影响。
- **不承诺**在离线状态下使用 B 站拉取、在线播放、模型下载或云端 AI。
- **可选**使用操作系统凭证加密保存 Cookie/API Key（Electron `safeStorage`；系统不支持时回退明文，见 [SECURITY.md](../SECURITY.md)）。
