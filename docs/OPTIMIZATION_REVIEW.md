# SubClip 高品质个人版优化记录

> 来源：`SubClip_高品质优化整合版.zip` 中的 `COMMERCIAL_REVIEW.md`，2026-10-24 合并进 3.16.1。
> 下文「整合包原始说明」保留原作者记录；「合并后验收」是本仓库在本机实际跑出的结果。

## 整合包原始说明

### 目标

不增加账号、支付、遥测、云平台等不必要的商业化负担。保留原有核心功能和数据结构，重点改善中文表达、可靠性、易用性及本地隐私。

### 已修改

1. 快捷命令、导航提示、字幕导入等界面的中文表达，减少术语和不自然的功能描述。
2. 字幕导入流程：阻止重复提交；忙碌时禁止移除文件或关闭窗口；捕获异常并显示错误；部分文件失败时保留对话框，便于查看失败原因。
3. 设置保存：先写临时文件再重命名，降低保存中断造成 settings.json 损坏的概率。
4. 敏感配置：在 Electron safeStorage 可用时，加密 Cookie、浏览器配对令牌、AI API Key。读取时兼容旧版明文配置；首次再次保存时会迁移为密文。加密能力不可用时仍沿用明文存储以保持功能可用，不能将此视为所有系统上的强制加密。
5. 键盘导航：为焦点增加可见轮廓，并支持系统减少动画偏好。

### 仍需注意（合并前）

- 该包是源码优化版本，未完成 Windows 实机安装和 GUI 端到端验收。
- 原作者环境没有安装 node_modules，因此未能实际运行 Vue/TypeScript 类型检查、Electron 打包和自动化测试。
- 本次没有大规模改写数据库、视频导出、IPC、AI 接口或语义检索算法，避免在缺少测试环境时引入数据丢失和兼容性问题。
- 本次仅完成关键页面的中文文案修订，不能声称全部 UI 文案已逐句审查。
- 不建议直接覆盖个人现有数据；先备份原有 userData。

### 推荐验收流程（合并前）

安装依赖后运行 npm run typecheck、npm test、npm run build。Windows 上重点验证首次启动、旧设置迁移、Cookie 与 API Key 保存/读取、字幕导入（成功/部分失败/错误文件）、搜索、视频剪辑导出、窗口关闭和再次启动。

## 合并后验收（2026-10-24）

- 合并范围：与 3.16.0 逐文件比对后确认，整合包相对本仓库只有 5 个源码文件差异（`src/main/settings.ts`、`ImportDialog.vue`、`AppNav.vue`、`commands.ts`、`polish.css`）和本文档；其余文件完全一致，没有夹带构建产物或可执行文件。
- 类型检查：`npm run typecheck` 通过（vue-tsc + tsc）。
- 自动化测试：`npm test` 通过。core / refactor / wbi / slice 全过；SQLite 冒烟 45 项通过 0 失败（新增「设置：旧明文可读，保存后敏感字段加密且无临时文件残留」）；桥接 38 项通过 0 失败。
- 生产构建：`npm run build` 通过。
- GUI 冒烟：用临时 `--user-data-dir` 启动真实 Electron 源码应用，首页正常渲染；「导入字幕文件」弹窗的防重、忙碌禁用和部分失败文案可见，未选文件时「导入字幕」保持禁用。
- safeStorage 端到端：通过真实 IPC 保存 Cookie / 桥接令牌 / AI Key 后，磁盘 `settings.json` 中三个字段均为 `safeStorage:v1:` 密文且无明文；再次读取可正确解密；没有 `.tmp` 残留。
- 已知未覆盖：真实 B 站账号登录与拉取、FFmpeg 网络下载/安装、视频剪辑导出全流程、Windows 安装包签名、macOS/Linux 实机。加密在系统密钥环不可用时仍会回退明文。
- 数据与回滚：升级前已备份源码与旧整合包；密文与当前系统用户绑定，换机或回滚到 3.16.0 前需要重新填写 Cookie / 令牌 / AI Key。
