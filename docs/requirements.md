## 1. 项目概述

开发一个由**桌面端应用 + 浏览器插件**组成的字幕处理系统。

目标：

- 高效浏览、检索和选择 Bilibili 视频字幕。
- 根据字幕选择自动生成视频时间切片坐标。
- 将坐标发送至本地批量切片工具。
- 支持本地 SRT 文件和 Bilibili 字幕获取流程。

## 2. 系统组成

### A. 桌面端应用

负责：

- SRT 字幕管理
- 字幕阅读、搜索、选择
- 时间范围计算
- 数据管理
- 与切片工具通信

### B. 浏览器插件

负责：

- Bilibili 页面检测
- 视频信息同步
- 字幕获取联动
- 与桌面端通信

## 3. 桌面端功能需求

### 3.1 字幕来源

**来源 1**：本地上传 SRT 文件。

支持：

- UTF-8 编码
- 常见 SRT 格式
- 格式异常处理

**来源 2**：整合已有字幕获取工具。

- 路径：`D:\bili_subtitle_extension_native_v1.2.8`
- 要求：
  - 阅读代码结构。
  - 提取字幕获取核心逻辑。
  - 尽可能融合进新工具。

### 3.2 字幕浏览

提供类似时间轴检索器的阅读体验。

字幕显示：

- 编号
- 开始时间
- 结束时间
- 文本内容

支持：

- 上下滚动
- 当前字幕高亮
- 自动定位
- 快速跳转

### 3.3 搜索

支持：

- 文本搜索
- 关键词高亮
- 时间定位

### 3.4 字幕选择

每条字幕提供复选框。

支持：

- 连续选择
- 非连续选择
- 多段选择

### 3.5 时间坐标生成

- 连续字幕：取第一条字幕开始时间和最后一条字幕结束时间。
- 非连续字幕：分别生成多个独立时间范围。

示例：

```json
[
  { "start": "00:01:20", "end": "00:02:15" },
  { "start": "00:10:30", "end": "00:11:20" }
]
```

### 3.6 切片工具连接

- 目标目录：`D:\subtitle2clip\bilibili-slice-downloader`
- 要求：
  - 阅读该工具代码。
  - 分析输入格式。
  - 自动生成其需要的批量切片参数。
  - 尽可能提取必要代码融合。

## 4. 浏览器插件需求

### 4.1 页面检测

支持检测：

- 视频页面
- 合集页面
- 收藏夹
- 投稿页面

获取：

- 视频 ID
- 标题
- URL
- UP主信息

### 4.2 桌面端同步

插件通过本地通信同步视频信息。

推荐：`localhost WebSocket`。

### 4.3 字幕获取

插件负责：

- 调用 Bilibili 字幕获取流程。
- 将字幕发送给桌面端。

## 9. 开发阶段

- **Phase 1**：SRT 读取、展示、搜索、选择、时间计算。
- **Phase 2**：连接批量切片工具。
- **Phase 3**：完成 Bilibili 插件和字幕获取整合。
- **Phase 4**：优化 UI、设置、快捷键。

## 10. 最终目标

实现完整工作流：

```
Bilibili 视频
  → 获取字幕
  → 字幕检索
  → 选择片段
  → 自动生成时间坐标
  → 批量切片
  → 输出视频片段
```

### 文档之外额外实现的能力

原始文档没有要求、但作为「字幕工具」明显需要，因此一并做了：

- **本机直接切片**：解析 DASH 分片索引，只下载目标片段，调 ffmpeg 裁剪合成，无需浏览器扩展参与。
- **跨文档全库检索**：一次搜遍库里所有视频 / 分P 的字幕，结果可直接批量加入切片任务。
- **批量编辑**：批量查找替换（支持正则）、时间轴整体平移 / 倍速缩放、编辑撤销。
- **字幕导出**：SRT / WebVTT / 纯文本，可把同一视频的全部分P 合成一份。
- **数据可迁移**：老版本的 JSON 存储会自动迁移进 SQLite，原文件改名留档。
- **数据管理**：整库备份 / 恢复（单个自洽的 `.db`，恢复失败自动回滚）、导出脱敏诊断信息、一键清空。
- **删除可撤销**：删除节点会先留快照，可以连同字幕正文、标签与切片任务整棵恢复。
- **用户自定义标签**：一个视频可打多个标签，资源树顶部「标签」分组按标签聚合，删除标签不影响视频。
- **切片任务工作流**：任务可排序 / 改名、导出与导入 JSON、命名模板（备注即输出文件名）；
  每次切片留下逐条历史（成功 / 失败 / 已取消 + 输出路径 + 错误原因），失败的可一键重试。
- **拖拽导入**：把字幕文件拖进窗口即可导入，无需走「选择文件」对话框。
- **右键菜单与无障碍**：资源树与字幕行都有右键菜单；资源树实现为标准的 `tree` 角色，
  键盘可完整操作（Enter/空格打开、左右键收放、`F2` 重命名）。
- **双语对照**：同一视频有多条字幕轨时，可并排显示另一条轨（同分P 内按序号对齐，退化为时间重叠匹配）。
- **字幕合并 / 拆分**：勾选多条右键合并（中文直接连、拉丁词之间补空格），或把一条从指定时间点拆成两条；
  批量编辑带**撤销 / 重做**（`Ctrl+Z` / `Ctrl+Y`，内存里各保留 20 步）。
